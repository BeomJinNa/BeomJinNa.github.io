01 · 개인 프로젝트

TinyRenderer

C++20 · DirectX 12 · HLSL · CMake

모델·텍스처를 불러와 화면에 그리는 개인 렌더링 엔진입니다. 파일을 읽는 부분, 장면 데이터를 관리하는 부분과 GPU 작업을 실행하는 부분을 나누어 구성했습니다.

설계와 구현 →
API 의존성 분리
렌더링 코드가 사용하는 인터페이스와 DirectX 12 구현을 분리했습니다. Vulkan 확장도 고려해 디스크립터 바인딩 규칙을 정했습니다.
데이터 변환
파일 파싱에는 외부 라이브러리를 사용하고, 읽은 데이터를 공통 중간 데이터로 변환한 뒤 엔진 자원을 생성하도록 구성했습니다.
GPU 자원 수명
업로드 작업을 동기화하고, 해제 요청된 자원은 해당 GPU 작업의 fence 완료를 확인한 뒤 회수합니다.
