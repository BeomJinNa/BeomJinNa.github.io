C++20과 DirectX 12로 구현한 개인 렌더링 엔진

모델·텍스처를 엔진용 데이터로 변환하고, 장면 갱신부터 렌더 패스 실행과 GPU 자원 회수까지 연결했습니다.

  • C++20 · HLSL · CMake
  • DirectX 12
  • Personal project

Scope

구현 범위

엔진 코어
장면과 에셋 관리, 렌더 패스 구성, GPU 명령 기록과 성능 측정을 구현했습니다.
RHI 계층
현재는 DirectX 12 백엔드를 사용하며, Vulkan 백엔드 확장을 고려해 렌더링 코드와 그래픽스 API 구현부 사이에 공통 자원과 명령 인터페이스를 두었습니다.
외부 라이브러리
tinygltf·Assimp·DirectXTex는 모델과 이미지 파일을 읽는 데 사용하며, 읽어온 데이터는 엔진 전용 중간 데이터로 변환해 에셋 관리와 렌더링에 사용합니다.

셰이더 자원 바인딩

DX12와 Vulkan에서 같은 HLSL 소스를 재사용할 수 있도록 공통 바인딩 규칙을 정했습니다. DX12는 레지스터 종류가 다르면 같은 번호를 사용할 수 있지만, 공통 레이아웃에서는 Vulkan 확장을 고려해 같은 그룹 안의 바인딩 번호가 서로 겹치지 않도록 제한했습니다.
